# Pedros Systems

Professional app-style demo for **Pedros Systems**, built with Next.js.

## Demo login

- Client: `demo@pedrossystems.com` / `Pedros123`
- Admin: `admin@pedrossystems.com` / `PedrosAdmin123!`

## Features

- Responsive landing page
- Client/Admin login demo
- App-style dashboard
- Projects, tasks, clients, invoices, files, services and support
- Browser persistence with `localStorage`
- Ready for GitHub + Vercel

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this repository in Vercel. Framework preset should be **Next.js** and Root Directory should be `./`.

> This repository is a fully interactive demo. For real multi-user production data, connect a managed database such as Supabase/Postgres and replace demo authentication.
